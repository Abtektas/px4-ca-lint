# CA004: PX4 ignores an axis with weak authority

Level: warning

## What it checks

Every effectiveness value of an axis is 0.05 or smaller, but not all are zero.
PX4's `control_allocator` module sets such a row to zero before it inverts the
matrix, so that the allocation does not try to control an axis with only
marginal authority.

## Why it matters

The parameters describe some authority on that axis, but PX4 does not use it.
If the axis is meant to be controlled, for example yaw on a multirotor, the
vehicle will not respond on it.

## What to do

If the axis should be controlled, check the parameters that produce it. For
multirotor yaw that is the moment coefficient `CA_ROTORn_KM`. If the small
values are an intended side effect, the finding can be ignored with
`--ignore CA004`.
