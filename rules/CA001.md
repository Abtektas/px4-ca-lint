# CA001: PX4 produced no usable effectiveness matrix

Level: error

## What it checks

PX4's actuator effectiveness class returned no matrix for these parameters, or
the configuration has no motors and no servos at all.

## Why it matters

Without actuators the control allocator has nothing to command. The most
common cause is a missing `CA_ROTOR_COUNT`: rotor positions such as
`CA_ROTOR0_PX` are ignored for every rotor index at or above the count, and the
count defaults to 0.

## Example

`examples/no_rotors.params` sets rotor positions but not `CA_ROTOR_COUNT`.
[CA021](CA021.md) names the rotors that are left out.

## What to do

Set `CA_ROTOR_COUNT` (and the servo counts if the vehicle has control surfaces
or tilts) and check that `CA_AIRFRAME` matches the vehicle.
